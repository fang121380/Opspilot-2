# 桌面学习链扩展验证（2026-09-10）

原工作台只有五节概览课，难以支持持续学习。本次扩展到 26 课：准备 1、Docker 7、Kind 5、Kubernetes 9、排障 4。课程顺序从进程、镜像、构建、网络和数据，推进到集群、声明式应用及故障复验。

## 交付内容

- 21 节深入课，每课有至少三段机制与场景讲解、命令证据、情景题、应用任务、参考思路和官方资料；原五课补充学习衔接正文。
- 总计 60 条模拟课程命令。新增命令全部为固定只读查询样例；网页不执行 Shell 或集群变更。
- 章节目录、章节筛选、课程搜索、先修课链接和数据驱动进度计数。原五课有效成绩保留，新课不自动完成。
- 新增分析笔记和逐项自评；深入课程完成要求非空笔记及全部验收项。自评不等于自动评分或实机验证。
- 四份内置实机手册：网站构建、Kind 镜像交付、Kubernetes 部署、故障恢复。补充完整 Compose/DNS/后端请求、PVC 文件跨 Pod 重建保留、ServiceAccount/Role/RoleBinding 正反权限检查。
- 电脑端手册支持宽屏阅读及章节跳转，深色模式链接有非颜色识别标记。

## 验证边界

本次以电脑端课程为主；未执行真实 Docker/Kind/Kubernetes 部署、故障注入或回滚，手册实机步骤仍需学习者在隔离环境验收。YAML 解析不代替 Kubernetes API 校验。未重新运行主 API 后端全套门禁，后端服务、代理白名单和真实执行代码未修改。

课程时长是建议预算，不是实测完成时间。模拟快照是字段节选，各课场景独立；任务自评不证明独立操作能力。课程建立一个应用的交付与排障链，不宣称覆盖全部生产高可用、认证、Helm/GitOps、集群升级或服务网格知识。手机联网问题按用户要求暂缓处理。
