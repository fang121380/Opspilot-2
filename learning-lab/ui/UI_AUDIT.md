# UI 审计 / UI Audit

- 用户：从零学习 Docker/Kubernetes 的开发者；首要任务是完成阶段实验并读懂证据。
- 信息层级：当前 context 与集群状态 > 资源/事件 > 练习步骤 > 终端输出。
- 工作流：选择阶段 -> 查看目标 -> 执行只读命令 -> 对照事件 -> 重试或记录状态。
- 数据密度：资源表适合桌面横向比较，小屏保留可横向滚动的最少字段。
- 状态：已有 ready、pending、warning、selected、disabled、错误提示和命令输出；后续接 API 时补充 loading/empty skeleton。
- 风险：集群写操作、Token、Secret、外部链接均不在模拟层执行；当前按钮只改变本地状态。
- 移动端：侧栏变为可横向滚动阶段条，资源表保持受控滚动，练习卡片单列。
